Using a font in GB Studio

  1. Press GB Studio (.zip) on a font above and unzip it.
  2. Copy the .png and .json into your project's assets/fonts folder.
  3. In GB Studio, open Settings › UI Elements and pick it as the default font, or switch to it with the Set Font event.

Letters you only drew in one case are used for both. The type test on each font shows what GB Studio will show: the same widths and the same line breaks.

Accented letters and the other Latin-1 characters (é, ñ, £, ½…) work in GB Studio as you type them. So do the symbols on the game's second page (← ↑ ♥ ★ ♪ “ ” … € ™ and more): the .json maps them to the font's characters 128–159.
