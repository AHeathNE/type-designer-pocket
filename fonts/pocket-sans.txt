# Pocket Sans: the reference font for Type Designer Pocket.
# Drawn for this project; SIL Open Font License 1.1 (fonts/OFL.txt). The game uses it for its own text and as the light-grey guide under each glyph.
#
# Metrics match GB Studio's built-in fonts:
#   row 0      accents / dots
#   rows 1-6   capitals and ascenders (row 1 = cap line)
#   rows 2-6   x-height
#   row 7      descenders (the baseline sits under row 6)
#   column 0   left blank so text has a gap
#
# Format: ": <char>" then 8 rows of 8, '#' = ink, '.' = blank. Codes 32-126, then 128-255, in order
# ("space", "nbsp" and "shy" name the invisible ones; 128-159 are the symbols listed in tools/tdpsave.py).
#
# Codes 192-255: accented letters start from this font's own A-Z and a-z. Accents sit on rows 0-1, and
# accented capitals drop one row to fit under them (as in IBM's VGA font).
